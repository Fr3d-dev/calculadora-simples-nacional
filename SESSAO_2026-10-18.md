# Sessão 2026-10-18 — Base CNAE × LC 116

Registro da conversa e dos resultados desta sessão.

## Objetivo
Construir uma base confiável que ligue cada **subclasse CNAE** ao **item da LC 116/2003**
correspondente, substituindo a heurística de casamento por palavras soltas.

Regras do usuário (obrigatórias):
- Ler a **frase inteira** da descrição, nunca casar por palavra-chave isolada.
- A descrição precisa fazer **sentido para o CNAE**.
- Não inventar item; se não houver correspondência confiável, marcar como
  `atividade_nao_servico` ou `nao_classificado`.

## Artefatos gerados
| Arquivo | Função |
|---|---|
| `_itens_lc116.json` | 207 subitens da LC 116 normalizados (sem cabeçalhos `.00`) |
| `_parse_itens_lc116.py` | extrai itens do texto bruto |
| `_fix_itens_lc116.py` | remove cabeçalhos `.00`, vetados e duplicados |
| `_cnae_map.py` | `SUBCLASSE`, `SERVICO_CLASSES`, `NAO_SERVICO`, `CLASSES_EXTRA`, `CASO_A_CASO` |
| `_ajustes_classe.json` | overrides por classe (4/5 dígitos) |
| `_ajustes_sub.json` | overrides por subclasse (`"1234-5/67"`) |
| `_build_cnae_base.py` | gera a base aplicando a precedência |
| `cnae_lc116.json` | **saída final** |
| `_valida_base.py` | validador (exige 0 erros / 0 avisos) |
| `_audita_itens.py` | relatório de itens usados com contagem e texto |

## Precedência aplicada no build
```
AJUSTES(sub) > SUBCLASSE > AJUSTES_CLS(5) > AJUSTES_CLS(4) >
CASO_A_CASO > SERVICO_CLASSES > CLASSES_EXTRA > NAO_SERVICO > regex
```

## Comando padrão
```powershell
python _build_cnae_base.py; python -X utf8 _valida_base.py
```

Status: **aprovado pelo usuário**.

## Bugs encontrados e corrigidos
1. **Cabeçalhos `.00` sobrescrevendo subitens.** Ex.: `18.00` sobrescrevia `18.01`;
   `18.01` acabava com o texto de "regulação de sinistros". Corrigido filtrando
   os cabeçalhos na lista de itens.
2. **Item `15.00` não existe** na LC 116 → bancos/auxiliares passaram a `15.07`
   (movimentação de contas) e `6619` a `15.12` (custódia).
3. **Item `16.00` não existe** → `4930` passou a `16.02`.
4. **`5911` apontava para `13.01`, que é VETADO** → corrigido para `13.03`.
5. **`_ajustes_sub.json` corrompido**: vírgula sobrando e chaves duplicadas;
   o build quebrava. Reescrito de forma válida.

## Armadilhas do ambiente (PowerShell 5.1)
- Separar comandos com `;` — `&&` não funciona.
- `python -c "..."` com aspas aninhadas/list comprehension quebra → criar script `.py`.
- Usar `python -X utf8` para imprimir acentos sem erro de encoding.
